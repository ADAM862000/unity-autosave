# Changelog

## [1.0.0] — 2026-06-10

### Added
- Auto save with configurable triggers: After Delay, On Focus Lost, Before Play Mode, Before Compile
- Dirty-state detection — skips saves when nothing has changed
- Debounced timer — won't interrupt active editing
- Scene and asset scope toggles
- Project Settings panel (Edit → Project Settings → Auto Save)
- Tools menu (Tools → Auto Save)
- Scene View toolbar overlay (Unity 2021.2+)
- Console verbosity: Silent / Minimal / Verbose
- EditorPrefs persistence — no project files modified
- Instant settings hot-reload
- NUnit test suite
- UPM package manifest
