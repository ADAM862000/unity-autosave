# unity-autosave

Smart auto save for Unity Editor by [Adam Abuarab](https://github.com/ADAM862000).

## Install

**Window → Package Management → Package Manager → + → Install package from git URL:**

```
https://github.com/ADAM862000/unity-autosave.git?path=com.adamabuarab.autosave
```

See [`com.adamabuarab.autosave/README.md`](com.adamabuarab.autosave/README.md) for full documentation.
